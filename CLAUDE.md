# Tilde · demo de cafetería de especialidad (paquete Básico)

Marca ficticia. El sitio es la **fachada del café**: toldo, letrero Abierto/Cerrado, "Arma tu taza", pizarrón,
pan del día con la hora real, reseñas en vasos y bolsa lateral. Ficha completa de diseño: `docs/tilde.md`.

- Sitio: https://demo-cafe-tilde.vercel.app (Vercel `demo-cafe-tilde`). Repo `BrunoDunay/Demos-cafeter-as-restaurantes`: push a `main` publica.
- Código: workspace de Angular 22 en `frontend/` con la app `projects/cafe-tilde`. Estático prerenderizado, CSS + IntersectionObserver.
- Comandos (desde `frontend/`): `npm start`, `npm run build` (sale en `dist/cafe-tilde/browser`).

- Convenciones de tacto: igual que en `2-Demos/Gimnasio/CLAUDE.md`.
